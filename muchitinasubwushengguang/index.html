深度解析

无圣光版本的可核对边界：修正了哪些，没修正哪些

判断：muchitinasub无圣光的「无圣光」并不等于「原片未删」，它只承诺不叠加人工遮挡层；照度、反射与烟雾等原片自带处理一律保留。因此拿它与港台播出带比对时，画面差异多数来自片源，不来自字幕组。

可反驳点若后续 BD 源本身带有创作者追加的修正图层，则「差异来自片源」这条推论需要按版本年份重新切分。

一、三处常被误认成「修正」的镜头，实际是片源差异

2026-10-18 放出的《雾港十日谈》第3话 Web-DL 版与 10-24 放出的 BD 版逐帧对比，有 3 处亮度与雾效差异：浴室镜面的反光强度、码头夜戏的雾密度、室内台灯的色温。三处 BD 版都比 Web 版暗 3—7 个 IRE，这是制作方在 BD 阶段普遍会做的降噪与调色，与任何字幕组的处理无关。

  • 10月18日《雾港十日谈》第3话 Web-DL 1080p 放出，字幕 356 行，无遮挡。
  • 10月24日同话 BD 源放出，画面亮度整体下调，字幕行未增减。
  • 11月1日论坛帖子把它列为「无圣光版二次修正」，帖内未给出逐帧坐标。
「把 BD 的调色当成字幕组的修正，是比对方法出了问题——先把两份片源放在同一播放器、同一色彩配置下再看。」—— 校对员林岚，2026-11-05 组内讨论

二、字幕层的改动可以做逐条核对

和画面相比，字幕改动更容易验证，因为 ASS 文件本身就是纯文本。把《凛冬列车》第4话 v1 与 v2 的 Dialogue 行取差集，得到 7 条变化：3 条错字修正、2 条时间轴位移（+4 帧、-3 帧）、1 条断句合并、1 条术语替换。v2 的发布说明只提到「通风扇」和两处时间轴，另外 4 条没有写进公告。

三、「无圣光」这个说法在站内的实际含义

组内工作文档把它定义为「不添加遮挡、裁切、马赛克三类人工处理」，并没有承诺内容完整。2026-09 至 11 月的 93 话样本里，实际出现过的处理只有两类：OP 前情提要与正片重叠时的字幕避让、以及 TV 版本身自带的静止画插入。前者属于排版，后者属于片源，都不改变镜头内容。

能核对的

  • ASS 文本逐行差分
  • 字体与字号是否一致
  • 时间轴位移帧数
  • 术语表版本号（当前 v9）

不能只靠截图判断的

  • 画面亮度是否被改
  • 雾效浓度变化归因
  • 色彩配置是否相同
  • TV 与 BD 的镜头库差异

结论可以拆成两条：字幕层改动可逐条验证，且 v2 公告未覆盖全部改动；画面层差异在没有统一播放器配置的情况下不宜下结论。把这两层混在一起讨论，是 10 月下旬几场争论的主要来源。

使用与安装指南

从下载到正确挂载字幕

  1. 确认片源与字幕版本对应

    外挂 ASS 按 Web-DL 与 BD 分别打包，帧率分为 23.976 与 24 两种。先看文件名里的 [WebDL] 或 [BD] 标记，配错版本会出现整体提前或延后。

  2. 安装字体包再挂字幕

    字体包 v3.2 含思源黑体、方正准圆、思源宋体三套子集。把 .ttf 装入系统字体目录后重启播放器，否则 ASS 会回退到默认字体，样式里的描边与阴影会变形。

  3. 在播放器中调整时间轴偏移

    若片源是电视录制版，开头通常有 2—5 秒台标与广告残留。用播放器快捷键把字幕整体平移，再保存为本地偏移，下次打开同一文件会自动套用。

  4. 切换简繁与注释轨

    单文件内以轨道区分：轨道 1 简体、轨道 2 繁体、轨道 3 日文注音注释。注释轨只保留术语与拟声词说明，不重复正文字幕。

  5. 反馈错译的写法

    在对应作品页留下时间码（时:分:秒:帧）、原文听写、建议译法三项。只写「这句不对」而没有时间码的反馈，校对通常排在最后处理。

常见问题

关于版本、字体与反馈
muchitinasub无圣光的「无圣光」具体指什么？

指成片不叠加人工遮挡、裁切与马赛克三类处理，镜头内容按片源原样保留。原片自带的照度调整、烟雾与静止画插入不属于「圣光」范畴，因此不会因为标注了无圣光就被移除。

《凛冬列车》第4话 v1 和 v2 应该下哪个？

下 v2。v2 修正了「換気扇」的误译，并调整了 2 处时间轴（+4 帧、-3 帧），另含 3 条错字修正。v1 已从归档目录移除，旧链接会跳转到 v2 的条目说明。

ASS 字幕装了字体还是显示成方块怎么办？

先确认字体包版本是否为 v3.2，再检查播放器是否启用了「使用 ASS 内嵌样式」。如果系统字体缓存未刷新，注销后重新登录一次即可；MPV 用户可在配置中加上字体目录路径。

简体轨和繁体轨可以同时挂载吗？

不建议。两轨在同一时间段会重叠，字幕会叠成两层。正确做法是在播放器字幕菜单里二选一；需要对照时，把其中一轨导出为文本再逐行比对。

发现错译后多久会被处理？

带时间码、原文听写与建议译法三项的反馈，通常在下一次同作品发布时合并处理，间隔约 3—10 天。缺时间码的反馈会进入待确认队列，没有固定处理时间。

BD 版字幕能否直接用在外挂的 Web-DL 片源上？

多数情况不能。BD 版补了镜头，总时长与章节点都变了，直接套用会从第一个补镜处开始整段错位。需要先用章节标记对齐，再逐段校正。
